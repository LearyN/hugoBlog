⑥ 规则说明

  • 只看自然搜索（GSC page 级 clicks / impressions / CTR / position），不含付费。
  • 过滤门槛：曝光 ≥ 300、排位 ≤ 10、付费占比 ≤ 50%、非本周新发、非自我竞争污染。
  • 题材基准按题材分别计算（谍照 ~2.7% vs 评测 ~0.9%，差 3 倍），不用全站均值，避免误判。
